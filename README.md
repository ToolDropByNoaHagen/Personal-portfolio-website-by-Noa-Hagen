# ToolDropByNoaHagen — Portfolio

A self-built portfolio site, designed and coded entirely by me — from the
first sketch to the final line. Built with vanilla HTML, CSS and JavaScript.

## What's inside

- A landing page with an interactive 3D object in the hero
- Smooth page transitions between pages
- An interactive "Archive" gallery where projects slide horizontally
- A detail view that opens per project, with cover, description and link
- Fully responsive — works on desktop and mobile

## Built with

- HTML, CSS & JavaScript (no build tools)
- [Three.js](https://threejs.org/) for the 3D object
- [GSAP](https://greensock.com/gsap/) for animations and transitions

## Structure

- `index.html` — landing page
- `archive.html` — project archive / catalogue
- `style.css` / `archive.css` — styling
- `script.js` / `archive.js` — 3D object, animations, interactions
- `Assets/` — 3D model, images and fonts
